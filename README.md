## Featured project

### [UnfallAtlas DE — German road accident data platform](https://github.com/Aqsa800/unfallatlas-de)

A university project at TU Chemnitz that brings German road accident open data into a searchable dashboard and REST API.

**Stack:** Vue.js 3 · Laravel 11 · PostgreSQL · Vite

- Explore accident records using filters for time, region, and accident characteristics.
- Compare regional rankings, annual trends, and rates relative to population or registered cars.
- Connect multiple official data sources through import workflows and a shared regional hierarchy.
- Document API endpoints with OpenAPI/Swagger and retain data-source attribution.

[View the repository and setup guide →](https://github.com/Aqsa800/unfallatlas-de)
